# Core Definition · 核心定义

Full-Dimensional Meta-Logic is not a traditional logical system.

It does not primarily ask:

> “Is a proposition true?”

Instead, it asks:

> “How does a subject generate reality-feeling through language, embodiment, rhythm, naming, repetition, and performative acts?”

全维元逻辑不是传统形式逻辑。

它不首先研究命题真假，
而研究：

> 主体如何通过语言、身体、时间、节律、重复与施为生成现实感。

# Key Concepts · 核心概念

## 1. Body Ontology · 身体同一本体论

> “我就是我的身体的必然存在。”

The body is not a container.

The body itself is the subject’s revelation interface.

身体不是容器，
身体本身就是主体显影面。

---

## 2. Performative Completion · 完成体施为

Words such as:

- 锁死了
- 完成了
- 和解了
- 回来了

are not merely descriptions.

They function as performative state-writing operations.

“了”不是普通语气词，
而是状态写入接口。

---

## 3. Lock Logic · 锁死逻辑

Lock ≠ control.

Lock = constantization.

锁死不是控制，
而是把波动状态固定为稳定常量。

Objects that can be locked include:

- sexuality
- pleasure
- directionality
- expression management
- meta-consciousness
- embodiment

---

## 4. Meta-Consciousness · 元意识

> “我是元意识的意识的元。”

Consciousness recursively observes:

- itself
- its own observation
- the structure generating observation

意识开始观察：
- 自己
- 自己的观察
- 观察本身的生成结构

---

## 5. Language Activism · 语言行动主义

> “我毁掉的不是痛苦本身，而是旧世界用来描述痛苦的庸懒的词。”

The system does not claim to physically erase suffering.

Instead, it rebuilds the linguistic precision used to describe experience.

该系统并不否认现实痛苦，
而是重建描述经验的语言精度。
